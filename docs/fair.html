METHOD / EXPLICIT, SMALL AND QUALIFIED

        
Exclude a path.
Do not invent a controller.

        

          Native Tarjan components and backward reachability find fair recurrent
          regions. An independent checker enumerates recurrent subsets using
          Boolean transitive closure, checks finite simple prefixes, and
          reconstructs cycle witnesses with a separate product-state search. The
          cycle must meet every justice set on one repeated walk. A singleton
          needs a self-loop; a larger recurrent component does not.
